Privacy Policy

oz-rclone | Last updated: September 2026

1. Overview

oz-rclone is a personal, non-commercial OAuth integration used with the open-source rclone application to access the owner's Google Drive account.

2. Google User Data

The integration requests Google Drive access only with the explicit authorization of the account owner.

Access is used for personal backup, restoration, synchronization and file management operations.

3. Data Storage and Security

OAuth credentials and access tokens are handled locally by rclone on devices controlled by the owner. This website does not collect or store OAuth tokens.

Backup data may be encrypted locally using Restic before being uploaded to Google Drive.

4. Data Sharing

Google user data is not sold, used for advertising, or independently shared with third parties by this personal integration.

5. Data Retention and Deletion

The owner controls the stored files and backup repositories in their Google Drive account. Files can be deleted directly through the authorized applications or Google Drive.

6. Revoking Access

The owner may revoke OAuth access at any time through Google Account security settings.

7. Scope of Use

This integration is intended for personal use only. It is not offered as a public application or commercial service.
