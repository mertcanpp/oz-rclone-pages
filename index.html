oz-rclone

Personal Google Drive Integration

About

oz-rclone is a personal, non-commercial OAuth integration configured for use with the open-source rclone software.

It enables the owner to access their own Google Drive storage for encrypted backups, restoration, synchronization and personal file management.

Data Usage

Google Drive access is authorized directly by the account owner. The integration is intended exclusively for personal use and is not offered as a public service.
